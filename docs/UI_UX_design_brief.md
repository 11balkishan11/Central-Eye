Objective
Design a world-class AI-native Infrastructure Operations Platform comparable to the design quality of:
•	Datadog 
•	Grafana Cloud 
•	Linear 
•	Vercel 
•	Notion 
•	Stripe Dashboard 
•	Arc Browser 
•	Raycast 
•	Superhuman 
•	Retool 
•	Apple Human Interface 
•	IBM Carbon 
•	Palo Alto Cortex 
•	CrowdStrike Falcon 
•	Cloudflare Dashboard 
The application should feel like a next-generation AI-powered Network Operations Center (NOC) rather than a traditional enterprise dashboard.
Users should immediately feel:
"This is the future of infrastructure management."
Avoid looking like:
•	Old enterprise software 
•	Bootstrap admin templates 
•	Generic Tailwind dashboards 
•	ERP software 
•	Government portals

UX Principles
Every screen should answer immediately:
1.	What is happening? 
2.	Is something wrong? 
3.	What should I do next? 
4.	Can AI help me? 
5.	What changed since last time? 
If the user cannot answer these within 5 seconds, the screen should be redesigned.

AI Builder Instructions (Non-Negotiable)
When generating the UI:
•	Do not use generic admin dashboard templates. 
•	Prioritize information hierarchy over visual effects. 
•	Use consistent spacing and an 8-point grid throughout. 
•	Build a component-driven interface where every element is reusable. 
•	Design for dark mode first, with light mode as a complete alternative. 
•	Ensure every module follows the same layout language, navigation patterns, and interaction model. 
•	Treat AI as a persistent copilot, surfacing insights and recommended actions contextually instead of hiding them behind menus. 
•	Optimize for users who spend 8–10 hours per day in the application: reduce cognitive load, minimize clicks, support keyboard shortcuts, and keep critical actions always discoverable. 
•	The final product should feel like a premium SaaS platform on par with the best modern enterprise software, not a traditional network management tool.
