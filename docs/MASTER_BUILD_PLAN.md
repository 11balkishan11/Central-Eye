# Master Build Plan

**Status**: Active Blueprint
**Goal**: Take NS3 Central from its current UI/CRUD foundation to a production-ready, highly scalable Network Monitoring Platform.

---

## 1. Current State
- **Fully Implemented**: Multi-tenant database schema, JWT Authentication, Hierarchical RBAC, Organization & Site management, Device CRUD (API only), Alembic migrations, frontend feature-folder architecture.
- **Phase 1 Complete**: Collector Registration, JWT Auth, Heartbeats, Job Pull API, Dashboard Synchronization.
- **Phase 1.5 Complete**: Job Leasing Semantics, Audit Events, Idempotency, Validation Matrix.
- **Missing**: The workers (ICMP, SNMP, Discovery) and TimescaleDB pipeline.

---

## 2. Development Order (The Path to v1.0)

This is the strict sequence in which the remaining features must be built to prevent architectural collapse.

### Phase 1: Collector Foundation ✅
**Goal**: Build the secure communication engine.
- Registration via Hashed Keys.
- Heartbeats (Capabilities/State Sync).
- Derived Offline Detection.

### Phase 1.5: Engineering Gate (Validation & Job Leasing) ✅
**Goal**: Stabilize the foundation.
- Centralize scheduling (Central owns, Collector leases).
- Idempotency and Correlation IDs.
- Audit Event Sourcing (`collector_events`).

### Phase 2: Job Execution Framework 🔄
**Goal**: Robust execution semantics on the Collector daemon.
- Lease jobs from Central.
- Idempotent Start/Complete/Fail lifecycle.
- Implement backoff and retry rules (driven by Central).

### Phase 3: ICMP Worker
**Goal**: Execute Ping Jobs.
- Gather Latency and Reachability.
- Provide real Up/Down operational state.

### Phase 4: SNMP Polling Worker
**Goal**: Extract operational metrics.
- Execute SNMP GET/WALK jobs.
- CPU, Memory, Interface Throughput extraction.

### Phase 5: Metrics Pipeline & TimescaleDB
**Goal**: Store the millions of metrics generated by the Collector.
- Install TimescaleDB extension in PostgreSQL.
- Convert `metric_series` into a Hypertable.
- Persist metrics with retention policies.

### Phase 6: Discovery Engine
**Goal**: Automate asset inventory.
- Network scanning (Ping Sweep).
- Device fingerprinting via `sysObjectID`.
- Automatic provisioning.

### Phase 7: Alerting & Automation
**Goal**: Tell the user when things break.
- Rules evaluation engine.
- Email/Slack Notifications.
- Escalation workflows.

### Phase 8: Production Hardening
**Goal**: Enterprise readiness.
- Docker Swarm / Kubernetes manifests.
- CI/CD pipelines.
- Multi-collector clustering load testing.
